3. INITIAL SERVER SETUP & SWAP MEMORY ALLOCATION
================================================================================
Connect to your server via SSH:
   ssh root@YOUR_SERVER_IP

Step 3.1: Update & Upgrade Packages
   sudo apt-get update && sudo apt-get upgrade -y

Step 3.2: Create an 8 GB Swapfile (CRITICAL: Prevents Out-Of-Memory / OOM kills)
   sudo fallocate -l 8G /swapfile
   sudo chmod 600 /swapfile
   sudo mkswap /swapfile
   sudo swapon /swapfile
   echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
   sudo sysctl vm.swappiness=10
   echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf

4. SYSTEM DEPENDENCIES & HEADLESS BROWSER INSTALLATION
================================================================================
Step 4.1: Install Node.js 20 LTS & Build Essentials
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs git build-essential

Step 4.2: Install Python 3.10+, Pip, and Virtualenv
   sudo apt-get install -y python3 python3-pip python3-venv

Step 4.3: Install Chromium & Headless Display Libraries (Required for Playwright/Puppeteer)
   sudo apt-get install -y xvfb libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 \
   libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxrandr2 libgbm1 libasound2 \
   libpangocairo-1.0-0 libpango-1.0-0 libxshmfence1 libglib2.0-0

Step 4.4: Install Global PM2 & Vercel CLI
   sudo npm install -g pm2 vercel

9. 24/7 PROCESS MANAGEMENT WITH PM2
================================================================================
PM2 ensures automatic restart upon crashes, RAM capping, and log rotation.

Launch the unified engine using PM2:

1. Launch Master Autonomous Controller Bot & Web UI:
   pm2 start "node controller_bot/index.js" \
     --name "arclane-controller" \
     --cwd "/root/agency-bots/arclane-engine" \
     --max-memory-restart 500M

2. Launch Interactive Core Analyzer Bot:
   pm2 start "node src/index.js" \
     --name "arclane-analyzer" \
     --cwd "/root/agency-bots/arclane-engine" \
     --max-memory-restart 800M

3. Launch Google Maps Scraper Command Center (Optional standalone listener):
   pm2 start "/root/agency-bots/arclane-engine/scraper/venv/bin/python telegram_bot.py" \
     --name "arclane-scraper" \
     --cwd "/root/agency-bots/arclane-engine/scraper" \
     --max-memory-restart 800M
