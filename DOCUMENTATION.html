Arclane 24/7 Autonomous Acquisition Engine

The complete technical manual and codebase reference for the end-to-end automated client acquisition system.

1. System Overview

This repository is a completely autonomous pipeline designed to acquire clients for web design, marketing, and B2B services. It replaces an entire sales team by running continuously 24/7. It scrapes leads from Google Maps, deep-crawls their digital footprint, generates AI-powered audits, automatically writes and deploys a custom website for them, and drops a highly personalized pitch into their WhatsApp inbox—all entirely unsupervised.

2. Full Command Reference

The system can be controlled interchangeably via the Telegram Bot or the Local Web UI (http://localhost:3000). Below is an exhaustive list of every command the Controller Bot accepts.

Global Controls

CommandDescription
/startInitializes the bot, loads the daily scheduler, and prints the main interactive keyboard.
/statusDisplays real-time system state, active processes (idle/running), current target niche, and the timeline for today's cron jobs.
/todayReads week_1_plan.json and outputs today's explicit blueprint (Scrape Query, Target Leads, Batch Sizes, Phone Close scripts).
/start_autoResumes the automated cron scheduler if paused. Enables 24/7 background mode.
/pause_autoSuspends all scheduled cron jobs (e.g. 9:30 AM scrapes, 12:00 PM dispatches). Manual commands will still work.
/reset_planAborts all currently running manual pipelines, flushes queues, and completely resets the state back to the scheduled 24/7 timetable. (Aliases: /resume_plan, /abort_and_resume).
/abort or /stopSends an immediate kill signal to all active Scraper, Builder, and WhatsApp threads. Halts the pipeline in its tracks.

3. Architecture & Code Walkthrough

The system is highly modularized under the src/ and controller_bot/ directories. Here is how every piece works.

3.1 Scraper (Google Maps) src/scraper.js

A sophisticated Puppeteer crawler that navigates Google Maps. It accepts a search query (e.g., "Gyms in Pune") and scrolls through the listings panel.

  • Stream Architecture: Unlike traditional scrapers that run to completion, this scraper emits a onLeadFound callback the microsecond a lead is extracted. This allows the Pipeline to start building the website while the scraper continues searching.
  • Deep Profile Scanning: If a lead does not have a phone number listed on Google Maps, the scraper opens their linked website, bypasses GDPR modals, and scans the DOM tree using Regex to aggressively hunt down hidden phone numbers and WhatsApp wa.me links.

3.2 Pipeline Runner & Scheduler controller_bot/pipeline_runner.js & scheduler.js

The "Brain" of the operation. The Scheduler loads the timetable from JSON and uses node-cron to fire off tasks. The PipelineRunner manages the complex async queues using p-queue.

  • Race Condition Prevention: The runner checks for existing processes and manages a strict state machine (this.isProcessing) to prevent two cron jobs from overlapping.
  • Real-Time Broadcasting: Injects dynamic import() calls to stream live log updates to BOTH Telegram and the Local Web UI simultaneously.

3.3 Summarizer (Gemini AI) src/summarizer.js

Connects to the Google Gemini API. It takes the raw scraped JSON (ratings, review count, business name) and produces a structural Markdown response.

  • 14-Point Audit: Analyzes the business profile to generate credibility scores and identifies "leaking revenue" (e.g., "Only 40 reviews? Your competitors have 200.").
  • Copywriting: Generates the exact personalized WhatsApp hook to be sent to the owner, dynamically injecting their actual business name.

3.4 Website Builder (Vercel) src/builder.js

The most complex component. This takes the AI audit and turns it into a live React/HTML page.

  • Local Generation: Writes HTML files to the generated_sites/ directory, embedding TailwindCSS and dynamic business data.
  • GitHub Commits: Uses simple-git to commit and push the new site to your remote repository.
  • Vercel Deployment: Executes npx vercel --prod --yes via Node's child_process.execAsync. It automatically creates the Vercel project, links the GitHub repo, and captures the live production URL output (e.g., https://business-name.vercel.app).

3.5 WhatsApp Dispatcher src/whatsapp_sender.js

A headless (or visible) Puppeteer instance that connects to web.whatsapp.com using an injected persistent profile session (whatsapp_user_session) to avoid scanning QR codes repeatedly.

  • Navigation: Uses the wa.me/PHONE URL scheme to open direct chats with prospects without saving them as contacts.
  • Safety Sweeps: Validates if the Vercel URL placeholder was properly replaced before hitting send. If it spots a placeholder, it skips the lead to avoid looking like a broken bot.
  • Human Emulation: Types characters with random delays, uses human-like pauses before sending, and spaces out bulk dispatches to prevent account bans.

3.6 Local Web UI src/web_ui.js

An Express.js + Socket.IO server running on port 3000. It provides an offline, self-hosted chat interface that completely bypasses Telegram API restrictions. It monkey-patches the Telegraf router so that any command sent via Web UI seamlessly triggers the exact same backend logic as Telegram.

4. Strategy JSON Configuration plan/week_1_plan.json

The entire intelligence of the bot is externalized into this JSON file. You don't need to write code to change the bot's behavior.

{
  "dayIndex": 3,
  "dayName": "Wednesday",
  "focus": "Premium Unisex Salons in Gurugram",
  "tasks": {
    "scraper": {
      "cronTime": "09:30",
      "query": "Unisex Salons",
      "city": "Gurugram",
      "targetLeads": 35
    },
    "dispatchWave1": { "cronTime": "12:00", "batchSize": 18 },
    "dispatchWave2": { "cronTime": "16:30", "batchSize": 17 }
  }
}

By simply altering this JSON file, you dictate exactly who the bot targets, when it wakes up, and how many messages it is allowed to send per day.
