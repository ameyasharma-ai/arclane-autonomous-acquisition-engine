Arclane 24/7 Autonomous Acquisition Engine

The authoritative, book-length technical reference for the unified client acquisition pipeline, integrated scraper, and 24/7 autonomous scheduling engine.

1. Executive Overview

The Arclane Engine is an autonomous multi-agent software suite built to replace an entire outbound sales and delivery agency. Working around the clock, it scrapes under-optimized local businesses from Google Maps, performs deep intelligence audits, automatically generates and deploys responsive websites to Vercel, and dispatches curiosity-driven outreach messages directly into prospects' WhatsApp and email inboxes.

Pillar 1: Ingestion

Google Maps Playwright Scraper

Deep DOM regex extraction, multi-source phone discovery, streaming events via IPC.

Pillar 2: Intelligence & Build

Gemini AI & Vercel Deployer

14-point SWOT & revenue audits, custom Tailwind site code generation, instant live production deployments.

Pillar 3: Conversion

WhatsApp & Sales Outreach

Persistent browser sessions, anti-ban rate limiting, non-sales curiosity pitches, and phone scripts.

3. Unified Architecture & Codebase Walkthrough

The codebase is organized into clean, decoupled layers located under scraper/, controller_bot/, and src/.

3.1 Internal Scraper Engine (scraper/)

Directly integrated into the repository root. Built on Python Playwright with asynchronous multi-page navigation.

  • Multi-Source Phone Extraction: In Indian markets, phone numbers are frequently placed inside WhatsApp click-to-chat links (wa.me/91...) or page body text rather than official Google Maps phone fields. The scraper executes a 3-tier regex scan:
    1. Official Google Maps phone buttons and metadata.
    2. Anchor tags scanning for wa.me/, whatsapp.com/send?phone=, and tel: protocols.
    3. Full DOM regex scanning targeting Indian 10-digit mobile patterns (+91, 0, starting with 6-9).
  • Stream Architecture: When executed by scraper_runner.js, the script emits real-time events over stdout: [STREAM_LEAD]: {"clientId": 105, "businessName": "...", "phone": "..."}.
  • Memory Safeguard (run_forever.py): Periodically cycles Chromium instances in 50-lead chunks to prevent browser memory leaks during 24-hour operations.

3.2 Real-Time Stream Pipeline Runner (controller_bot/pipeline_runner.js)

Coordinates the producer-consumer workflow using p-queue with a strict concurrency setting of 1 to ensure system stability.

// Stream Scraper Event Listener:
onLeadScraped: (leadObj) => {
    this.leadQueue.add(async () => {
        await this.processSingleLead(leadObj, sheet);
    });
}

As soon as a lead is extracted from Google Maps, its website is being analyzed, generated, and deployed to Vercel while the scraper moves to the next business.

3.3 24/7 Scheduler & Race Protection (controller_bot/scheduler.js)

Employs node-cron mapped to the Asia/Kolkata timezone. Integrates mutex flags (isProcessing) to prevent scheduled cron jobs from colliding with manually triggered runs.

3.4 14-Point Strategic AI Summarizer (src/summarizer.js)

Connects to Google Gemini Flash Lite or OpenRouter models using structured prompt engineering (src/system_prompt.txt). Analyzes SWOT, competitor gaps, review velocity, and produces tailored curiosity hooks.

3.5 Tailwind Website Builder & Vercel Deployer (src/builder.js)

Transforms AI prompt specifications into fully functional, high-conversion landing pages:

  • Enforces 100% solid, opaque headers to prevent overlap defects.
  • Implements backdrop blur drawers with generous spacing for mobile UX.
  • Automatically pushes code to GitHub via gh repo create and deploys live production domains via npx vercel --prod --yes.

3.6 WhatsApp Engine & Human Emulation (src/whatsapp_sender.js)

Uses Puppeteer with a persistent user data directory (whatsapp_user_session/) to maintain continuous authentication:

  • Randomizes dispatch intervals between 30 and 75 seconds.
  • Emulates natural typing cadence and pre-send pauses.
  • Validates that live website URLs are present before sending to eliminate placeholder errors.

3.7 Dual Sync Web UI & Local Persistence (src/web_ui.js)

Express.js + Socket.IO server running on port 3000. Features bidirectional chat synchronization with Telegram and JSON-backed history persistence in web_ui_history.json.

5. 24/7 Server Operations & Autostart

To run continuously on a Linux server (Ubuntu 24.04 LTS):

# 1. Install Node.js, Python, and PM2
sudo apt update && sudo apt install -y nodejs npm python3 python3-pip
sudo npm install -g pm2

# 2. Start Master Controller with Memory Guard
pm2 start controller_bot/index.js --name "arclane-controller" --max-memory-restart 1G

# 3. Configure PM2 Autostart on Server Boot
pm2 save
pm2 startup
