Producer-Consumer Streaming Architecture

Rather than waiting for the entire city batch of 35 leads to finish before starting website generation, the system operates as a real-time reactive stream:

Phase 1: Producer

Google Maps Scraper

Extracts business cards on Google Maps. As soon as Lead #1 is saved to Google Sheets, it emits a [STREAM_LEAD] event over IPC and continues scrolling for Lead #2 in parallel.

Phase 2: Stream Worker

BI Audit & Site Builder

Picks up Lead #1 immediately from the queue. Crawls existing web presence, runs 14-point SWOT audit, generates mobile-first Tailwind code, and publishes to GitHub + Vercel (*.vercel.app).

Phase 3: Dispatcher

WhatsApp Outreach

Ready websites enter the dispatch queue. Dispatched in two high-conversion waves (12:00 PM & 04:30 PM) with 30–75s safe delays and vCard address book synchronization.

The 5 Operational Pillars

1 Google Maps AI Scraper & Watchdog (`gmaps-scraper-Indian`)

Python + Playwright

Maintains 24/7 scraping stability with an autonomous Watchdog. If Chromium freezes for $>3$ minutes, it safely terminates the process and resumes without losing progress via scraped_places.txt. Cleans data via Gemini Flash Lite and writes directly to Google Sheets.

2 24/7 Autonomous Controller Bot (`controller_bot/`)

Node.js + Telegraf + Cron

Executes your weekly timetable automatically: 09:30 AM Real-Time Stream Scrape & Build $\rightarrow$ 10:30 AM Safety Sweep $\rightarrow$ 12:00 PM WhatsApp Wave 1 $\rightarrow$ 04:30 PM WhatsApp Wave 2 $\rightarrow$ 06:00 PM Deal-Closing Phone Reminder. Controlled remotely via Telegram inline buttons.

3 14-Point Strategic BI Audit & Website Builder (`src/`)

LLM + GitHub CLI + Vercel CLI

Crawls existing prospect sites, generates SWOT and SPIN hooks, converts Antigravity prompts into modern Tailwind websites with design quality gates (solid headers, fluid typography, mobile drawers), creates GitHub repos, and deploys live production domains to Vercel.

4 WhatsApp Curiosity Outreach Engine (`src/whatsapp_sender.js`)

Playwright Web Session + vCard

Exports one-tap .vcf address book contacts to your phone and automates WhatsApp Web sends with randomized 30–75s anti-ban delays, sharing the business owner's custom live website.

5 Sales Email Dispatcher (`sales_bot.py`)

Python Telegram Bot

Interactive Telegram interface to review leads, preview drafted HTML emails, and attach formatted CSS-styled SEO Audits (Website_UX_SEO_Audit.html).

24/7 VPS Deployment & PM2 Setup

Step 1: Create 8 GB Virtual Swap (Zero-Crash Guard) 

sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

Step 2: Start 24/7 Process Manager (PM2) 

# Install PM2 globally
sudo npm install -g pm2

# Start Autonomous Controller Bot
pm2 start controller_bot/index.js --name "arclane-controller" --max-memory-restart 1G

# Start Main Analyzer & Builder Bot
pm2 start src/index.js --name "arclane-analyzer" --max-memory-restart 1G

# Start Google Maps Scraper Command Center
pm2 start "python telegram_bot.py" --name "gmaps-scraper" --cwd "../gmaps-scraper-Indian" --max-memory-restart 1G

# Persist across server reboots
pm2 save
pm2 startup

Troubleshooting & Emergency Playbook

WhatsApp Web Requires QR Scan

In Telegram Analyzer Bot, send /login to open the browser window and scan the QR code. Sessions persist in whatsapp_user_session/.

Google Sheets 403 Permission Error

Open your Google Sheet $\rightarrow$ Click Share $\rightarrow$ Add the email from service_account.json as an Editor.

Vercel Deployment CLI Error

Run npx vercel login on your server terminal or set VERCEL_TOKEN="..." in your .env file.

Scraper Freezes on Google Maps

The built-in Watchdog will automatically detect 3 minutes of silence and restart. To manually restart, send /stop then /scrape ... in Telegram.
