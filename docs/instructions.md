# Rebuild This Next.js SaaS Template Into an Apple-Level Web Development & Data Analytics Agency Website

You are an expert **creative director, UX/UI designer, brand strategist, conversion-rate optimizer, and senior Next.js engineer**.

You are working inside an existing Next.js repository based on the `NextJSTemplates/play-nextjs` template.

Your job is to **completely transform this existing template into a world-class, premium web development + data analytics agency website**.

Do NOT simply modify the existing SaaS pages.

Treat the current repository as an **engineering foundation** and rebuild the visual identity, information architecture, copy, interactions, and user experience around a premium digital agency.

# 18. MOTION DESIGN

Use motion carefully.

Preferred animation principles:

- 150–500ms transitions
- smooth easing
- subtle staggered reveals
- opacity + transform
- tasteful hover states
- scroll-triggered reveals
- subtle parallax where appropriate

Use Framer Motion / Motion or the animation system already present in the project when appropriate.

Do not animate everything.

The animation hierarchy should be:

1. Page transitions
2. Section entrances
3. Important interactive elements
4. Micro-interactions

Respect:

`prefers-reduced-motion`

Users who disable motion should receive a clean static experience.
