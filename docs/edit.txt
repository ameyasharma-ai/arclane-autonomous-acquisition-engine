==================================================
IMAGE RESPONSIVENESS RULES
==================================================

Preserve the COMPLETE IMAGE whenever the image is intended to be shown as a full visual.

Do NOT:

- Stretch images
- Squash images
- Distort aspect ratios
- Crop important content accidentally
- Cut off screenshots
- Cut off UI dashboards
- Cut off portfolio designs
- Use arbitrary fixed widths that break mobile layouts
- Use fixed heights that cause image clipping
- Allow images to overflow their containers
- Create horizontal scrolling
- Make important content disappear on smaller screens

For images where the entire image must be visible:

- Preserve the original aspect ratio.
- Use appropriate responsive sizing.
- Prefer width: 100% / max-width: 100% where appropriate.
- Use height: auto when appropriate.
- Use object-fit: contain where an image is placed inside a constrained container and the entire image must remain visible.
- Use object-fit: cover ONLY where cropping is intentionally part of the design and does not remove important content.
- Ensure the parent container itself is responsive.
- Avoid hardcoded heights unless there is a strong design reason.

For Next.js Image components:

- Use appropriate width/height or fill configuration.
- Use responsive sizing correctly.
- Use sizes attributes where applicable.
- Ensure images don't cause layout shifts unnecessarily.
- Do not use `fill` blindly.
- Make sure the parent container has the correct positioning and dimensions when using `fill`.
